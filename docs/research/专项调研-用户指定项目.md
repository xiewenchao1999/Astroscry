## 二、可直接落地的算法与数据（详细）

### 1. 五行旺衰量化（BaziEval → core/bazi 升级）

算法三步（潘爱民，经验值表完整收录于其 README，原文链接见仓库）：

1. **天干强度**：查「生月 × 天干」表取系数（1.0–1.2）。得令者 1.2（如甲乙在子/卯/亥月），失令 1.0。
2. **地支强度**：按支藏干分权重——本气约 0.7–1.2、中气约 0.2–0.36、土余气 0.5–0.6，同样随月支微调（12×12 表）。
3. **身强身弱**：日干五行 + 生我之五行 = 同类；其余 = 异类。差值大 → 不平衡；身强取克泄为用、身弱取生扶为用（原文承认「用神选取未完全量化」，v1 我们可只输出「同类/异类比值 + 身强/身弱结论 + 建议补的五行」）。

**验算例（将作为我们的测试向量）**：`戊申 辛酉 壬寅 甲辰`（1968-08-08 辰时）
金 3.24 / 木 2.0 / 水 1.8 / 火 0.3 / 土 1.5；日主壬水 → 同类（水+金）5.04 > 异类 3.8 → 身强，宜补火。

### 2. 称骨算命（yuan → 新功能）

数据文件（MIT 之外随意取用，自用范围）：
- `references/chenggu/references/lookup_tables.json`（2KB）：出生农历年（甲子骨重表）+ 月/日/时辰骨重查表
- `references/chenggu/references/verse_profiles.json`（28KB）：全部骨重对应的袁天罡歌诀档案
- 算法：年+月+日+时 四项骨重求和（几两几钱）→ 查歌诀 → 批注诗
- 落地：与八字页共享出生信息（需农历年月日时，我们已有农历输入与转换），实现成本半天级，产出独立「称骨」卡片或子页

### 3. 人生运势 K 线（life-kline → 八字页新视图）

- 概念：把每步大运/每个流年映射为蜡烛图 OHLC——例如 O=上一步承接分、C=本运综合分、H/L=区间内流年极值；牛市/熊市配色直觉化
- 其实现：React + 图表组件（LifeKLineChart.tsx 16KB 可参考坐标轴/十字光标交互）；分数来源其站内为 AI 报告，**我们改为确定性评分**：流年天干地支 vs 日主十神（吉神+凶神加权）× 月令旺衰系数（BaziEval 表）
- 附赠：`assets/data/celebrity_cases.json`（12KB 名人命盘案例库）可作「名人命盘对比」素材

### 4. 《四柱编程》书稿（sizhu-programming → 语料库）

- `sizhu_programming.md`（66KB）是全书正文：概念定义统一、规则步骤展开、边界条件明确——正是我们「规则层+语料层」需要的知识形态
- 落地：按章节抽取「确定性规则」补入 interpret-bazi.json（标注【释义】级），「经验性判断」保留为扩展语料
