## 一、可迁移的四条生成纪律（来自开源 skill 的共识）

1. **可推导（Derivable）**：每句话都能追溯到当天真实天象（月相/月落星座/太阳位置/行星相位）。禁纯随机拼句。
2. **非宿命论（Non-fatalistic）**：用「倾向于 / 可能 / 适合 / 留意」替代「一定 / 必将 / 会」。全部文案过一遍语气检查。
3. **评分平衡**：五维（总/爱/事业/财/健康）分数总和约束在 14-19（均值 2.8-3.8/5），禁止全高或全低——同一天 12 星座拉不开差距是最常见的生成事故。
4. **同日 12 座互斥**：每座必须回扣本座核心特质（白羊=冲、金牛=稳、双子=变……），禁止复制改名。

## 二、Transit 权重体系（决定当日基调）

| 因子 | 来源 | 权重 | 用途 |
|---|---|---|---|
| 月亮星座与月相 | astronomy-engine 可算 | ★★★★★ | 当日情绪基调主轴 |
| 太阳位置 | 可算 | ★★★★ | 日段能量 |
| 水/金/火快行星 | 可算 | ★★★ | 具体事件色 |
| 大相位（日地夹角型） | 可算 | ★★ | 加减压定调 |
| 星期 / 节气 / 季节 | 本地历法 | 辅助 | 节奏锚（周一=起步感，周日=收束感） |

本项目已有 astronomy-engine，此表可直接落成规则引擎的因子权重。

## 三、句式模板库（中文，按段落组织）

### 3.1 开场句（总体运势，2-3 句）
- 「今天{天象主语}落在{星座}，你的{星座特质词}有了放大器——{顺境动作}。」
- 「{月亮相位}的余韵还在，情绪面{升/降/稳}，适合{匹配动作}。」
- 「对{星座}而言，今天是{四档词}的一天：{一句话概括基调}，重点在{领域}。」

### 3.2 领域句（爱/事业/财/健康，各 1-2 句）
- 爱：「感情里{行星主题}先行——{有伴场景句}；单身的你{单身场景句}。」
- 事业：「{四档词}节奏下，{具体动作}比{反面动作}更划算，尤其{时间窗}。」
- 财：「{星座金钱观}的你在今天{理财动作}；{金额/决策提醒}。」
- 健康：「{星座易耗点}容易报警，{低成本补救}就能回血大半。」

### 3.3 幸运元素块（结构化输出，非段落）
- 幸运数字：从星座幸运数库（见 corpus/western/zodiac-signs.json 的 lucky.numbers）中按 seed 取 2 个
- 幸运色：lucky.color + 当日轮换
- 幸运时段：与「旺/顺/平/滞」档位映射（旺=上午黄金段，滞=下午缓冲段）
- 今日关键词（Power word）：与 advice 档位联动

### 3.4 收尾句（Daily Tip，必须具体）
- 「❌ 空话：今天整体不错，保持好心态。」
- 「✅ 具体：下午三点后回复工作消息，把早上留给最难的那件事。」
- 反巴纳姆纪律：建议必须绑定「什么时间 / 做什么动作 / 对什么对象」，任一为空即打回。

## 四、输出结构参考（来自两个 skill 的模板合并）

```
# {符号} {星座} 每日运势（{日期} {星期}）
## 总体 {星级} ({n}/5)      ← 2-3 句
## 爱情 {星级}              ← 1-2 句
## 事业 {星级}              ← 1-2 句
## 财富 {星级}              ← 1-2 句
## 健康 {星级}              ← 1-2 句
## 幸运指南                  ← 数字/颜色/时段/今日速配
## 今日一句                  ← 一句可执行建议
```

本项目可把星级映射到既有「旺/顺/平/滞」四档（4/3/2/1），无需改成五星。

## 五、与现有语料的接口

- `interpret-horoscope.json` 的 signs.*.advice 四档 → 对应 3.1 开场句的「四档词」
- signs.*.domains 六域 → 3.2 领域句的素材池
- signs.*.keywords → 「回扣本座特质」的锚词
- corpus/western/zodiac-signs.json 的 lucky/element/modality → 幸运元素块 + 评分修正项（同元素当日互为国运参考）
