## 二、选定结论（决策表）

| 领域 | 选定 | 角色 | 替代方案（被拒原因） |
|---|---|---|---|
| 紫微排盘 | **iztro** | 运行时引擎（vendor） | ziwei-doushu 引擎（更重，Next.js 形态难浏览器直用；取其数据弃其引擎） |
| 紫微解读语料 | **ziwei-doushu 公版古籍** | 静态数据（转化为 JSON） | docs/tianji-ziwei 倪海厦讲义（版权存疑，只学不用） |
| 八字/历法 | **lunar-javascript** | 运行时引擎（vendor） | tyme4ts（解读辅助少）；sxtwl（需编译） |
| 天文历表 | **astronomy-engine** | 运行时引擎（vendor） | Swiss Ephemeris（AGPL）；CNHJS（停更） |
| 星盘渲染 | **AstroChart** | 运行时引擎（vendor） | 自绘 SVG（备选，若 AstroChart 定制受限再切） |
| 塔罗数据 | **Waite 公版文本**（参照 ekelen/tarot-api 结构） | 静态数据（转 JSON + 中文释义自译） | corpora/McElroy（许可待核，仅补充） |
| 每日运势 | **自研规则算法**（真实天象 + 星座关键词库） | 自研 | 爬取式 API（不可靠/停更） |

**选型一致性**：四条线全部 MIT 或公有领域，可商用、可静态化、可离线；均为浏览器端运行 → 无后端、无数据库、生日数据不出浏览器（隐私即卖点）。

> **实施期更新（2026-10-14）**：AstroChart v3 发行包无文档且深度耦合 DOM，实施时改为本项目自绘 SVG 星盘轮（`site/js/ui/wheel.mjs`），已从 vendor 移除 astrochart。其余选型不变。

## 三、风险与规避

1. **子时/真太阳时**：v1 仅做出生地经度平太阳时校正（可开关），均时差校正留待后续（`ponytail:` 记录上限与升级路径）。
2. **宫位制**：v1 用整宫制（whole-sign，计算无歧义），Placidus 后续再上。
3. **塔罗图片**：RWS 扫描图为公有领域（sacred-texts/Wikimedia）；若网络不可达，v1 降级为纯排版卡面（不阻塞）。
4. **解读文案质量**：非 AI 核心意味着解读=规则+模板+公版语料。文案质量上限取决于知识库整理质量，首版覆盖「星曜/宫位/组合」基础层级，页面明示「传统术数文化展示，非科学建议」。
5. **lunar 单文件 436KB / iztro 体积**：静态站可接受，不做裁剪（YAGNI）。
