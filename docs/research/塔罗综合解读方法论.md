# 塔罗综合解读方法论调研（牌间关系 / 叙事综合）

> 调研日期：2026-10-15 · 方式：开源仓库源文件精读 + 公开方法论文章交叉核对
> 目的：为 `interpret-tarot.json` 的「综合解读」重写提供方法论依据。现状痛点：五段式（起点/张力/转折/出口/回响）的模板句是**空洞框架**（「给出了来处」「从这里出发」），没有用到牌与牌之间的关系，任何一手牌读起来都一样。

---

## 一、核心发现：综合解读的质量差在「牌间关系层」

单张牌义（78 张，已有）只回答「这张牌说什么」；综合解读的价值在回答「**这些牌放在一起怎么说**」。检索到的三个来源给出高度一致的方法论：

### 1. tarot-skill（daman-ovo-0404，MIT）——牌间关系两层架构

`references/card-relations.md`（全文精读）给出可完全确定性化的分类体系：

**A 层（任意相邻两牌可用的通用关系）**

| 编号 | 体系 | 规则 |
|---|---|---|
| A1 | 大阿卡纳「愚人之旅」 | 编号上升 = 推进；倒序 = 补课；跨幕（0–7 / 8–14 / 15–21）= 跨度大 |
| A2 | 同花色小牌「数字旅程」 | 小到大 = 推进；大到小 = 重启；围绕 5 = 危机位 |
| A3 | 牌性（Elemental Dignities，源自黄金黎明） | 火⇄风互助、水⇄土互助、火⇄水蒸发（相克）、风⇄土僵化（相克）、火土需落地、水风易情绪化 |

**B 层（特殊结构，命中优先）**

| 编号 | 体系 | 规则 |
|---|---|---|
| B1 | 镜像张力 | 两张大阿卡纳编号相加 = 21 |
| B2 | 宫廷牌 = 角色 | 宫廷牌是局面里的人物（或问卜者的一副面孔），另一张是事件 |
| B3 | 阶段共振 | 同数字不同花色——同一人生阶段在两个领域呼应 |

`references/combinations.md` 给出 10 组经典组合（死神+星星=结束后的疗愈、高塔+星星=崩塌后重建、月亮+太阳=幻象被照亮、恶魔+力量=驯化阴影、女祭司+魔术师=直觉与行动校时、隐士+恋人、皇帝+命运之轮、正义+命运之轮、死神+审判、高塔+宝剑十=旧结构彻底结束）。

### 2. Elemental Dignities 的通行口径（多来源交叉一致）

Thalira / 占星塔罗教程均确认同一套规则：**火+风互助（风助火势）、水+土互助（互相滋养）、火+水相克（互相削弱）、风+土相克（互相僵持）**；同元素为中性偏强化。RWS 花色对应：权杖=火、圣杯=水、宝剑=风、星币=土（与我们 `SUIT_ELEMENTS` 一致）。

### 3. 图案层（pattern reading）

- **大小阿卡纳层级**：大牌定「命运级主题」，小牌给「日常细节」（astratarot 等）。
- **宫廷牌**：人物、问卜者的侧面、或处事姿态；多张宫廷牌 = 人物戏份重。
- **王牌（A）**：新开端的强信号；多张 = 多线新开始。
- **数字连跑**：连续数字（如 3-4-5）= 一段按序展开的剧情。
- **花色集中度**：我们已有（suitDominant / suitMissing / majorBands / reversalBands），本轮不重复。

## 二、落地映射：引擎算「关系」，语料写「判词」，页面只拼装

延续本项目架构（core 产出结构化事实与语料键、文案全在语料、页面只渲染）：

| 关系 | 判定（确定性，core） | 语料键（interpret-tarot.json links 节） |
|---|---|---|
| 经典组合 | 牌对 id 排序后查表（B 层最优先） | `classic['ar13+ar17']` 等 10 键 |
| 阶段共振 | 两牌均为数字牌且 num 相等 | `echo`（含 {num}） |
| 镜像张力 | 双大牌且编号和 = 21 | `mirror` |
| 愚人之旅 | 双大牌，编号升/降 × 是否跨幕 | `majorUp / majorDown / majorUpCross / majorDownCross` |
| 数字旅程 | 同花色数字牌，升/降/含 5 或跨 5 | `suitUp / suitDown / suitFive` |
| 宫廷牌角色 | 任一为宫廷牌（双宫廷另有 `courtPair`） | `courtRole`（含 {court}{event}）/ `courtPair` |
| 主题×细节 | 恰好一张大牌 + 一张数字小牌 | `majorMinor` |
| 牌性 | 其余小牌×小牌按元素对 | `fireAir / waterEarth / fireWater / airEarth / fireEarth / waterAir` |
| 图案 | 王牌数 / 宫廷牌数 / 数字连跑（≥3 连续） | `acesNone/One/Many`、`courtsNone/Few/Many`、`runTpl` |

**连线只取相邻牌**（阅读顺序两两），不做全对全连——牌阵越长噪声越大，这也是 tarot-skill 与通行教学一致的做法。每对只取**一个**关系（优先级：经典 > 共振 > 镜像 > 旅程 > 宫廷 > 主题细节 > 牌性），避免一句牌对贴三张标签。

**五段式升级**：起点/张力/转折三句模板加入 `{kw}` 占位（取该牌正/逆位第一个关键词），把「空洞框架句」变成「引用牌面关键资讯的叙事句」。占位符与键名不变，纯文案替换（同键换文案 ≠ 破坏契约）。
