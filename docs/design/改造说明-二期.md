## 二、新功能使用说明

### 周易占卦（site/pages/iching.html）
- **三法起卦**：铜钱摇卦（默认，每爻三枚，3反=老阴6/2反1正=少阳7/1反2正=少阴8/3正=老阳9，老阴老阳为动爻）、梅花开局（以当下时刻按标准梅花时间卦：年支序+农历月+日取上卦、加时辰取下卦、总和取动爻，余 0 归模数）、三数法（随口报三数：n1 上卦、n2 下卦、三数和动爻）。
- **解卦**：变爻取辞严格按朱熹《易学启蒙》七档——0 动本卦卦辞；1 动本卦动爻辞；2 动两动爻以上爻为主；3 动本卦（贞）+之卦（悔）卦辞；4 动之卦两不动爻以下者为主；5 动之卦不动爻辞；6 动乾坤用九/用六、余卦之卦卦辞。卦象卡附卦辞白话、大象传、关键词、场景化卦意与四维建议；末尾错卦/综卦/互卦速览。
- 查询主键为 bits（六位二进制自下而上），core 内建 WeakMap 缓存索引；数据闭合由 validateIching（64 卦、bits 无重、386 爻辞）在页面加载时前置校验。

### 求签掷杯（site/pages/folk.html）
- **求签**：观音灵签 100 签（浅草寺体系），摇签动效（reduced-motion 自动跳过）→ 签诗/典故/分项解。分项解按 domainsOrder 16 类展示，按签非全键时显示「此签未列」，分项解卡固定带「释义为开源语料整理，仅供文化研究」注记。
- **掷筊验签**：抽签后可连掷三筊确认；独立「掷圣杯」tab 供单独问事（宜可否式提问）。判定口径（依 jiaobei-rules.md 三源一致）：一平一凸=圣筊（允）、两平=笑筊（未明，可再问）、两凸=阴筊/怒筊（否，宜改问法）；三掷总评=三圣筊允 / 见阴筊否 / 其余未明。

### 每日运势五维（horoscope 页 + 首页今日综合）
- 原有 0-95 总分与四因子（守护星相位/月亮元素/水星逆行/守护星逆行）不变，叠加五维：**总体/爱情/事业/财富/健康**（语料 horoscope-writing-patterns.md 口径），每维 0-4 分、总和按生成纪律约束在 14-19（越界等比缩放，防全高全低）。
- 每句评分因子保持「行星名+相位名+±分值」可回溯格式；详情卡五维分条（meter 条）+ 档位×维度建议句（health 句式全部自带就医提示，非宿命论措辞）。

### 塔罗 Waite 层（tarot 页）
- 每张牌新增「原文（Waite 1911）」折叠行（英文原文 + 中译对照）；宫廷牌追加「人物侧写」行（问「某人」类问题适用）。
- 牌间连线新增 12 组高频组合（恋人+恶魔、恶魔+高塔、月亮+审判等），与既有经典组合同表查用。
- 正逆掷币逻辑收敛进 core 的 drawCards（reversedRate 可注入，默认 0.5 与原行为一致）。

## 四、已知限制与升级路径（ponytail 汇总）

- **周易派系**：年支按 lunar-javascript 农历年（正月初一）而非立春换年；晚子时公式法属当日——见 core/iching.mjs 头注，升级路径=流派开关。
- **奇门时区**：castQimen(tzOffsetHours) 已参数化但仅按北京时间核验流派口径，其余时区开放前需补命例基准——见 core/qimen.mjs。
- **掷筊概率**：真实筊杯阴阳面着地概率非 50/50，v1 用均匀近似，升级路径=可配置面概率——见 core/jiaobei.mjs。
- **astro 配置面**：行星集/相位表/元素权重/个人行星集集中于 CONFIG，升级路径=迁 data 文件 + 页面开关（v1 不上 UI）——见 core/astro.mjs。
- **北交点/宫位制**：平交点解析式（误差 ≤1.5°）、整宫制（Placidus 升级路径），一期既有 ponytail 未变。
- **观音签分项解与爻辞白话润色**：O03 持续项（P1/L），本期完成进站级快扫（7 处硬伤修正 + 留档），1478 条分项解与 384 条爻辞的逐条润色按批推进，页面已固定「开源语料整理，仅供文化研究」注记。
- **六爻（卦爻起课）**：未立项。当前周易页覆盖 64 卦卦爻辞取辞，未做纳甲六亲/世应体系，如需可在 iching.mjs 基础上扩展（bits 索引与变卦计算可复用）。
- **掷筊命名口径依据**：两平=笑筊、两凸=阴筊（怒筊）取自 docs/research/round2/corpus/eastern/jiaobei-rules.md（维基百科「掷筊」条目与鼎稔道學馆三源组合判定一致；民间个别资料平/凸与阴阳命名互有出入，程序只依赖组合判定）。
