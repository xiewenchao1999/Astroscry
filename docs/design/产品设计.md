# 星卜 Astroscry · 产品设计 v1

## 定位

一站式网页占卜：西方星座（本命盘/每日星象运势）、塔罗、东方八字（四柱）、紫微斗数。
纯本地计算、零注册、零后端——生日数据不出浏览器，隐私是核心卖点，也是零运维成本的来源。

**目标用户**：对传统术数感兴趣的中文用户，想快速得到一份「说得清楚为什么」的排盘+解读。
**非目标**：社交、付费、AI 对话解命、专业排盘软件的全量功能（飞星/小限/推运等进阶项均不在 v1）。

## 页面与核心流程

| 页面 | 输入 | 输出 |
|---|---|---|
| `index.html` 首页 | 无 | 四大功能入口卡 + 今日干支/月相摘要（实时计算） |
| `pages/horoscope.html` 每日星象 | 选星座（或从生日推断） | 今日真实天象（月相/逆行/主要相位）→ 12 星座运势分级与文案 |
| `pages/natal.html` 西方本命盘 | 生日、时间、城市（经纬度选择器） | 行星落座落宫表、相位表、SVG 星盘轮、要素小结（元素占比/三态） |
| `pages/tarot.html` 塔罗 | 选问题类型 → 洗牌交互 | 单张/三张牌阵（过去·现在·未来），正逆位 + 牌义（中文化） |
| `pages/bazi.html` 八字 | 生日+时间+性别（+真太阳时开关） | 四柱干支、五行统计、十神、纳音、胎元/命宫/身宫、大运表、规则式简评 |
| `pages/ziwei.html` 紫微 | 生日+时间+性别 | 12 宫命盘（星曜/亮度/四化/大限）、命宫主星解读、本命四化说明 |
| `pages/about.html` 关于 | 无 | 数据来源与许可声明（公版古籍/MIT 库/CC 数据）、免责声明 |

## 解读引擎（非 AI 核心）

三层结构，全部确定性：

1. **计算层** `js/core/`：调 vendor 库产出结构化盘面（纯函数）。
2. **规则层**：把盘面特征映射为知识条目 key（如八字「日主甲木+月令子水」→ `bazi.jia.shui`；紫微「命宫紫微+左辅」→ 条目组合）。
3. **语料层** `data/interpret-*.json`：key → 中文文案（源自公版古籍整理 + 自写释义），渲染时按特征拼装、注明出处层级。

文案分级标注：`【古籍】`（公版原文）/`【释义】`（本项目自写）。页面底部固定免责声明。

## 交互原则

- 表单只问必要项：能推断的不让用户填（星座从生日推断、经纬度从城市选、时区从经度推）。
- 排盘前有 loading 态与明确的必填提示；排盘失败给下一步动作而非裸报错。
- 塔罗洗牌做成有仪式感的一步交互（点击洗牌 → 抽牌翻开），不让用户配置无关选项。
- 深色星空主题贯穿全站，排盘结果区为可读性优先的亮卡。

## 验收标准

- 四大功能在本地静态服务下全流程可走通（浏览器实测）。
- `node --test tests/` 全绿：八字/紫微/西占/塔罗各有 ≥1 条已知基准断言。
- 断网（除加载页面本身）情况下四大功能全部可用。
